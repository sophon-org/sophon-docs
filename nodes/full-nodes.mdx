<Warning>
  This is legacy Sophon v1 infrastructure. The chain is being wound down, and these
  docs no longer provide a path for launching a new Sophon full node.
</Warning>

A Sophon full node stored a complete copy of the chain and could reproduce and
verify Sophon state. The original roadmap also anticipated full nodes participating
as sequencers or validators as ZKsync sequencing became decentralized.

That forward-looking node roadmap is no longer active because the Sophon Chain is
being decommissioned. This page is retained only to explain the role full nodes had
in the legacy architecture.

For current Guardian NFT and reward handling, see the
[Guardian transition](/nodes/our-infra).
