<Warning>
  The Sophon Chain is being wound down. New deposits have been disabled since
  **June 25, 2026**. Connect to the network only as needed to review balances, claim
  rewards, or withdraw assets.
</Warning>

Use [claim.sophon.com](https://claim.sophon.com) as the primary interface for claims
and withdrawals. See the [migration guide](/migration) before taking action.

## Add Sophon to a wallet

If the portal asks you to connect directly to the legacy network, use:

```text Network Information
Network Name: Sophon
RPC URL: https://rpc.sophon.xyz
Chain ID: 50104
Currency Symbol: SOPH
Block Explorer: https://explorer.sophon.xyz
WebSocket URL: wss://rpc.sophon.xyz/ws
```

<Info>
  Always verify that your wallet shows chain ID `50104` and that you are using
  [claim.sophon.com](https://claim.sophon.com) before signing a transaction.
</Info>

## Withdraw from Sophon

1. Open [claim.sophon.com](https://claim.sophon.com).
2. Connect the wallet that holds your Sophon assets.
3. Select **Withdraw from Sophon** for the relevant balance.
4. Review the available route and destination carefully before confirming.

Sophon is no longer connected to LayerZero. SOPH withdrawals to Ethereum use the
canonical route; from Ethereum, SOPH can be bridged onward to other supported chains.
