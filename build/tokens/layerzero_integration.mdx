<Warning>
  Sophon was removed from the LayerZero network on **June 25, 2026**. Do not deploy
  new OFT routes to Sophon or call the former `LzOftHelper` contracts.
</Warning>

The previous Sophon-specific LayerZero integration and `LzOftHelper` flow are
retired as part of the Sophon Chain wind-down. Existing code samples were removed
because they no longer describe a supported production route.

For SOPH:

- withdraw from Sophon to Ethereum through the canonical route at
  [claim.sophon.com](https://claim.sophon.com);
- bridge from Ethereum to another supported chain through LayerZero.

For other assets on Sophon, use the claim portal's **Withdraw from Sophon** action.
It routes users through Jumper and shows the paths currently available for each
asset.

See [SOPH Bridging](/build/tokens/soph-bridging) and the
[chain migration guide](/migration) for current guidance.
